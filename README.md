### About me

I'm a frontend developer who has spent the last decade inside the Angular ecosystem, from AngularJS to Signals and standalone APIs. I'm at my best when a product needs to **scale, be modernized, or be untangled**: migrating legacy codebases, defining architecture and raising a team's code quality.

- 🏦 Currently **Senior Frontend Developer at Belender**, modernizing software used by banks and public administrations
- 🧭 Twice **Frontend Lead**: code reviews, architecture decisions and team follow-up
- 🤖 Daily user of **AI-assisted development** (Claude Code, GitHub Copilot) for refactoring, debugging and faster delivery
- 🌍 Working remotely with distributed teams since 2021

### What I've been doing lately

| | |
|---|---|
| **Legacy modernization** | Progressive migration of a production app from Angular 14 to 17+, adopting standalone components, the new control flow and Signals |
| **Reactive state** | Replaced manual `subscribe` chains with Signals and the `async` pipe, reducing memory leaks, and set clear criteria for Signals vs. RxJS |
| **Reusable architecture** | Built versioned internal libraries and moved business logic out of components into testable services, cutting duplicate code |
| **Quality standards** | Introduced a Jasmine/Karma unit test suite plus ESLint and Prettier, and standardized best practices across the team |
| **Team leadership** | Led frontend teams and shipped a V2 demo with Angular 18 and PrimeNG that closed a product sale |
